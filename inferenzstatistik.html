2.1 Alpha-Fehler

Simulation der Grundgesamtheit

IQ ist verteilt mit M = 100, SD = 15, Population von Mainz

iq_population <- rnorm(n = 220000, mean = 100, sd = 15)
summary(iq_population)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  34.27   89.96  100.05  100.06  110.16  166.57

Zwei Stichproben aus derselben Grundgesamtheit

Stichprobe A

sample_a <- sample(iq_population, size = 20)
summary(sample_a)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  65.66   87.99   97.07   98.55  107.57  140.32

Stichprobe B

sample_b <- sample(iq_population, size = 20)
summary(sample_b)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  63.12   84.84   97.74   96.81  103.86  129.57

Ein einzelner T-Test

t.test(sample_a, sample_b, var.equal = T)

    Two Sample t-test

Simulation von 1000 T-Tests

Wir vergleichen 1000 Mal zwei 20er Stichproben per T-Test und speichern die entstandenen 1000 p-Werte als p_vals ab.

p_vals <- replicate(n = 1000, {
  t.test(
    x = sample(iq_population, 20),
    y = sample(iq_population, 20),
    var.equal = T
  )$p.value
})

head(p_vals)
[1] 0.3277591 0.8006983 0.3906238 0.4958037 0.8417476 0.7549412
qplot(p_vals)

Fragen zum Alpha-Fehler

Frage 1: Wieviele p-Werte sollten signifikant sein (Alpha-Fehler)?

Antwort: Bei einem \(\alpha\)-Niveau von 0.05 sollten es ungefähr 50 von 1000 sein.

sum(p_vals <= .05)
[1] 49

Frage 2: Was sollte sich am Alpha-Fehler mit größeren Stichproben ändern?

p_vals_1000 <- replicate(n = 1000, {
  t.test(
    x = sample(iq_population, 1000),
    y = sample(iq_population, 1000),
    var.equal = T
  )$p.value
})
qplot(p_vals_1000)

Antwort: Nichts. Der Alpha-Fehler ist unabhängig von der Größe der gezogenen Stichproben.

sum(p_vals_1000 <= .05)
[1] 54
